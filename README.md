# LangGraph Agent Workflows

LangGraph notebook experiments for conditional, parallel, persistent, and chat-based agent workflows.

## Purpose

Agent systems need state, branching, persistence, and workflow control. This repository explores those LangGraph concepts through multiple notebook/app examples.

## What This Shows

- Sequential and conditional workflows
- Persistence and database-backed chat concepts
- Agentic AI workflow structure

## Stack

- Python
- Jupyter Notebook
- LangGraph
